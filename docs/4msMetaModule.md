# 4ms Meta-Module

Hey, isn't Liminal Rack the same as the 4ms Meta-Module that came out in '24? Well, no. 
The Meta-Module is quite interesting and a similar idea of using the VCV Rack standard 
to create patches on virtual modules. I even own one. But while it is a great step forward, 
it is greatly limited by the small display and not being a touch screen (which of course 
wouldn't make sense for a small display). 

The Meta-Module is not really a friendly interface for creating patches on. Seems that 
pretty much all users create patches on a dreaded general purpose computer and then
transfer the patch via a memory card to the Meta-Module. Also, whille the Meta-Module is
quite powerful CPU wise when compared to other modules, it still does not have enough
oomph to run even a medium sized patch. 

Therefore Liminal Rack is an attempt to provide the functionality that Meta-Module has, but
do so with a much nicer user experience.
